# lahsrocketry newsroom

The system behind the @lahsrocketry Instagram account of the Los Altos High
School Rocket Club. A local model drafts one post a day, humans approve it on
Discord, and a publisher posts it through Instagram's API.

- Vocabulary: `CONTEXT.md`
- Decisions: `docs/adr/`
- Design: `docs/design/modules.md`
- Setup for the account owner: `docs/setup/accounts-and-keys.md`
- Verified platform facts: `docs/research/`
