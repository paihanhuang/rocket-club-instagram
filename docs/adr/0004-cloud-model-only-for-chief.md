# Cloud model usage is limited to the chief; daily drafting is local

Daily drafting must run on the local model at zero marginal cost. The cloud model (Claude Code with Opus) is used only for the weekly chief run that writes the plan and for on-demand maintenance. This is a budget constraint, not a quality preference, and it shapes the design: the worker's tasks are kept narrow enough for a 27B model, and anything needing more judgment is moved into the weekly plan.
