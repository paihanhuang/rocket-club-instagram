# Club photos

Drop consented photos into `photos/consented/` and list each one in
`photos/consented/consent.json`:

```json
[
  { "file": "2026-09-20-build-night.jpg", "credit": "LAHS Rocket Club",
    "students": ["first names of everyone recognizable"], "consentedBy": "officer name", "on": "2026-09-20" }
]
```

A photo is used only if it is listed here. The fence forbids any student's face
without consent, so the list is the consent record. Faces of students not on
the list must not be in the photo.
